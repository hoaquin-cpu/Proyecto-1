# Tracker de Gastos Personales

## Proyecto

 Este es mi primer proyecto personal. Es un como dice el titulo un tracker de gastos personales hecho todo en HTML/CSS y JavaScript. No hace mucho en mi carrera aprendí el manejo de las API's y aunque todavia no lo habia dado, aprendi por cuenta propia a vincularlo con una base de datos. Todo esto esta a un nivel local y es demasiado básico.
